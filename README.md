# FSD-secure-task-app
secure task management system app of FSD project
Overview The Secure Task Management Application is a full-stack web application built to help users efficiently manage their daily tasks with a focus on security and simplicity. The system allows users to create, update, delete, and track tasks through an intuitive frontend interface and a robust backend API.
features:
User registration and secure login
Password encryption for data protection
Role-based access control (admin and user)
Create, update, and delete tasks
Set task priority and deadlines
Mark tasks as completed or pending
Secure data storage and transmission
Protection against common cyber attacks (SQL injection, XSS)
Search and filter tasks easily
Task reminders and notifications
Dashboard to view task status
Database integration for storing data
